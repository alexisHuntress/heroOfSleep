# 🌙 Hero of Sleep

> **A bedtime story where dreams become an adventure.**

Once upon a time, in a land of dreams and wonder, a kingdom lived in peace. Its people slept happily and dreamed happy dreams.

But one dreamer grew tired of that peace.

Using foul magic, he unleashed his nightmares into the land, took over the castle, and declared that happy dreams would be no more.

Yet all hope was not lost.

There lay an innocent young hero who dreamed of heroes and adventure.

**This is the story of how he became one.**

---

## 🛏️ About the Game

**Hero of Sleep** is a text-based adventure game built in Python with a Pygame interface.

Explore a strange dream dungeon, collect legendary bedtime equipment, solve puzzles, battle creatures of the night, and find your way to the Nightmare ruling the dream.

How the story ends depends on the path you take.

---

## ⚔️ Features

- Explore an interconnected dream dungeon
- Fight monsters with turn-based combat
- Collect eight pieces of legendary equipment
- Solve interactive puzzles including Hopscotch, Simon Says, and Hangman
- Discover hidden rooms and secret paths
- Use clickable controls or typed commands
- Track explored rooms with a discovery-based minimap
- Find multiple endings based on how you play

---

## 🎮 Commands

| Command | Action |
| --- | --- |
| `Move` | Move to another room |
| `Attack` | Attack an enemy |
| `Collect` | Collect an item in the room |
| `Puzzle` | Attempt the room's puzzle |
| `Run` | Attempt to escape from an enemy |
| `Equipment` | View collected equipment |
| `Help` | Display available commands |
| `Quit` | End the game |

Commands can be entered with the keyboard or selected using the Pygame interface.
